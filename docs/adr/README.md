# Architecture Decision Records

An ADR records one important decision: its context, the options we considered, what we chose and what follows from it. An accepted ADR is never edited; a new ADR replaces it and the old one is marked *Superseded*.

To add one, copy [`template.md`](template.md) to `NNNN-short-title.md` with the next number, and open a pull request.
