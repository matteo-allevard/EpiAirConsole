The sounds

Controller

Vibrations

On the phone, every important sound has a matching vibration. Yellow bars are vibrations, gaps are pauses, drawn to scale.

Vibrations work in the controller on Android (Chrome, Firefox). iPhone does not allow them on the web: sound and screen are enough there. They do not fire in this preview.

Usage rules

Keeping it pleasant

Always optional

A Sounds switch and a volume slider in the options of the console and the controller. Default volume: 60%.

Never alone

A sound never carries information on its own: every sound has a visual equivalent (colour, text, icon). Informative sounds are captioned.

Short and soft

Interface sounds last under 400 ms. Only the intro foghorn and the victory sound are longer.

No hover sound

The hover sound exists but is off by default: on a TV with eight controllers it would quickly become annoying.

Reduce motion

When the device asks for it, the beam stops, the lamp breathes and transitions become fades. Sounds stay.

Ambience in the background

The room ambience (low pad and waves) only plays on the waiting screen, never during a game.

Integration

In the code

TypeScript modules with no dependency. Sounds are generated in the browser: no audio file, no licence to credit.

example.ts 
import { createSfx, mountBeacon, type SoundName } from "@byoc/ui";

const sfx = createSfx({ volume: 0.6 });

// One sound on every element with data-sfx
document.addEventListener('click', (e) => {
  const el = (e.target as HTMLElement).closest<HTMLElement>('[data-sfx]');
  if (el) sfx.play(el.dataset.sfx as SoundName);
});

// A player joins: the note depends on their slot (0 to 7)
sfx.join(player.index);

// Waiting screen
const beacon = mountBeacon(document.querySelector<HTMLElement>('#beacon')!);
sfx.ambience(true);
// … when the room is ready
beacon.stop(); sfx.ambience(false); sfx.play('go');

// Player options
sfx.setVolume(0.6); sfx.setEnabled(false);
