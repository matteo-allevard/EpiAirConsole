# Game developer guide

> **Planned (Sprints 2 to 5).** This guide lets any developer build a game for Byoc without touching the platform code.

The SDK is **not a game engine**. Use any library you like to draw, animate and play sounds. The SDK is the link between your game and the console: it gives your game access to the players, their phones and the platform services.
