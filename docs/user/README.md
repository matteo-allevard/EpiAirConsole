# Getting started

> **Planned (Sprint 3).** Outline of this guide, for hosts and players with no technical background.

## For the host

- Open the console on a computer or a smart TV
- Create a room
- Choose and start a game
- Manage players (kick a player, hand over the host role)
- Set the accessibility options

## For players

- Join a room with your phone (QR code or room code)
- Understand the controller of each game
- Create an account (optional)
