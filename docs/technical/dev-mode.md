# Developer mode

> **Planned (Sprints 1 and 2).**

Developer mode lets you test a game with several players without any phone.

## Planned features

- **Controller simulator:** add 1 to 8 virtual controllers in the browser, each one showing the controller the game asks for
- **Message log:** every message between the server, the console, the game and the controllers
- **Latency:** live measurement from button press to on-screen reaction
